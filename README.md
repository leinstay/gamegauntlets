# Game Gauntlets

Backend and static frontend for [gamegauntlets.com](https://gamegauntlets.com), a random-game wheel: pick
filters, spin, land on a game from a large catalog aggregated from multiple game-data sources.

## Data

The public catalog export consumed by third parties is published at
[github.com/leinstay/steamdb](https://github.com/leinstay/steamdb).
